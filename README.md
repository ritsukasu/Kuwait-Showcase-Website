## About

Kuwait Country Showcase Website is a small front-end project created to celebrate the State of Kuwait (دولة الكويت). It presents the country through a simple, clean web page, with respect for its people, its history, and its culture.

Kuwait is a nation on the northwestern shore of the Persian Gulf, known for its warm hospitality, its seafaring and pearl-diving heritage, and the resilience of its people.

## The flag

The flag of Kuwait carries the Pan-Arab colors. Its horizontal bands of green, white, and red are joined by a black trapezoid at the hoist. Each color has long been associated with a theme in Arab and Kuwaiti tradition, and together they are a proud symbol of the nation.

## Getting started

This is a static site, so there is nothing to install.

```bash
git clone https://github.com/ritsukasu/kuwait-country-showcase.git
cd kuwait-country-showcase
```

Then open `index.html` in any modern web browser.
